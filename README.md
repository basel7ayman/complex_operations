# Complex Operations

This project is a small C++ program that models complex numbers and demonstrates operator overloading.

## What it does

The program defines a `Complex` class that supports:

- Addition, subtraction, multiplication, and division
- Assignment and comparison operators
- Prefix and postfix increment/decrement
- Index access and modulus-style magnitude calculation
- Input/output stream support

It is a practical example of object-oriented programming in C++ using user-defined operators for custom numeric types.

## File

- `complex_operations.cpp` — main implementation of the `Complex` class and sample usage

## Compile

From the project directory, run:

```bash
g++ complex_operations.cpp -o complex_operations
```

## Run

```bash
./complex_operations
```
